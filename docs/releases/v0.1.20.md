## Mux v0.1.20

本版重点为 Herdr Pulse 增加完整的常用 Git 工作流，并重新整理 TOKEN / GIT 导航与侧栏展示。以下说明覆盖自 v0.1.19 以来的更新，也包含 Grok 多账号、Codex 重置卡、会话识别和代理资源处理的改进。

### 新增：Herdr Pulse Git 工作流

- **仓库与更改列表**：跟随同一 Herdr 标签页最近聚焦的普通终端或 coding agent，自动识别项目仓库、子目录和 worktree；聚焦侧栏时保留仓库。展示当前分支、上游、领先 / 落后提交数，按 Unstaged、Staged、Conflicts 分组列出文件与增删行数，部分暂存文件可分别出现在未暂存和已暂存区域。
- **单文件与全部暂存**：`s` / Stage file 只暂存当前整个文件；`a` / Stage all 一次暂存仓库全部新增、修改和删除。`u` 取消暂存当前文件或 Diff 中选中的差异块，`U` 取消全部暂存；Ops 菜单提供整文件和选中差异块操作。
- **Diff 浏览**：Enter 打开当前文件；固定显示文件名、序号、暂存状态和差异块位置。`,` / `.` 切换上一个 / 下一个文件，`[` / `]` 选择差异块，Esc / Files 返回列表并保留选择。默认自动换行，`w` / Wrap ON/OFF 切换；关闭换行后可横向滚动。续行保留增删颜色和块归属，鼠标点击原行或续行都能选择正确的块。
- **撤销更改**：`d` 对未暂存文件或选中差异块操作，执行前确认；Diff 中 `D` 对整个文件操作。删除未跟踪文件会单独提示。已暂存内容得到保留，内容或暂存区发生变化时拒绝过期操作并提示刷新。
- **提交**：`n` / Commit 只提交已暂存内容，支持第一行标题和多行正文；Enter 换行，Ctrl+Enter / Review 进入确认，确认页 Edit / Esc 返回草稿。没有暂存内容、仍有冲突或暂存区在确认前变化时拒绝提交，沿用 Git hooks 与签名检查。
- **分支与远端**：点击仓库概览的 **⑂ 分支名 ▾** 按钮，或按 `b`，打开可搜索的分支选择页；选择本地分支后确认切换，选择远端分支后可建立本地跟踪分支。Ops 菜单还可创建分支、选择远端 Fetch、执行 fast-forward-only Pull，以及推送当前分支；首次 Push 可设置上游，不提供强制推送。
- **Git Log 与搜索**：`L` / Log 查看当前分支历史，每页 50 条，展示提交摘要、作者、日期和引用标签。Enter / Details 查看完整提交信息、文件统计和 Diff；详情自动换行，Esc 返回原提交。`/` / Search 搜索当前分支全部提交的标题与正文，采用不区分大小写的字面文本匹配，再分页展示结果；Clear / Ctrl+U 清空输入，Enter 恢复全部历史，Esc 取消搜索并保留原结果。
- **执行与结果提示**：Git 命令在后台串行运行，表单、确认和执行期间固定仓库，执行后刷新状态。错误与结果日志显示在按钮上方，`l` 可查看完整输出。沿用本机 credential helper / SSH 配置；需要交互认证时先在普通终端完成登录。

### 改进：互斥导航与 Git 界面

- 顶部 TOKEN / GIT 改为一组固定的互斥分段页签，`●` 标记当前页、`○` 标记另一页；重复选择当前页不会重置内容。Alt+1 / Alt+2 分别选择 TOKEN / GIT，`T` / `g` 也可直接选择。
- 切回 TOKEN 保留之前的统计子页、客户端筛选、排序和滚动位置；切回 Git 保留文件选择、Diff、Log 和搜索结果。编辑表单、确认及执行命令时暂时禁用页签选择。
- TOKEN 页压缩顶部页签、客户端筛选与内容之间的留白，状态提示直接放在底部按钮上方；账号进度条、重置时间、统计与会话模块之间不再插入额外空行，高窗口也不会增加间距。可视化账号卡在宽度足够时将进度条、百分比和重置时间放在同一行，窄屏保留完整信息。TOKENS 与 CODEX / GROK ACCOUNT 标题统一使用粗体和分隔线，日期保留在右侧，窄屏优先显示标题；账号菜单与滚动点击区域同步调整。
- 文件列表使用固定仓库概览，首行直接展示自动识别的仓库绝对路径，与分支选择按钮放在同一行；删除重复的项目名 / 分支标题行，分支按钮保留下拉标记并使用普通文字，不使用高亮背景。滚动时仍可查看路径、分支、上游和分组数量。文件名、目录和增删统计分层展示，新增 / 删除分别使用绿 / 红色；选中行有侧标与高亮背景，长文件名、目录与重命名信息支持换行和续行点击。
- 底部不再重复显示 Home 按钮，导航与操作分为两行。文件列表、Diff、Log、搜索、分支菜单、提交表单、确认和详情页面均显示对应按钮与提示；详情按钮标明返回 Log / Diff / Files，撤销与取消暂存明确区分整文件和差异块。
- 创建 / 跟踪分支使用 Enter / Review，提交消息使用 Ctrl+Enter / Review，提交确认页可返回草稿。空表单、无匹配菜单、翻页 / 滚动边界和执行中的操作按钮置灰；窄屏和短屏自动使用紧凑布局。
- Settings → Pulse → Start page 可选择默认打开 Git；TOKEN 首页、图表和 Sessions 继续沿用原有统计能力。

### 新增与改进：账号管理

- **Grok 多账号**：支持保存、导入、选择、应用、重命名和删除 OAuth 账号；账号切换与 API Provider 模式区分处理，保留其他账号凭据，失败登录不会覆盖当前可用登录。
- **Pulse 账号下拉菜单**：Codex / Grok 页面可按 `a` 或点击当前账号展开列表，选择后确认切换；菜单内嵌在账号卡中，额度和统计内容随之下移，切换异步执行并刷新账号与额度。首次打开 Grok 账号列表会保存已有本地 OAuth 登录。
- **Codex 重置卡**：账号页新增 Reset / `R`，先查询可用卡并显示所选账号、卡片和有效期，二次确认后兑换一张并刷新额度；使用隔离登录副本，不切换当前账号。兑换失败或超时不自动重试，成功兑换但刷新失败会明确提示。
- **Grok 额度展示**：补充官方网页额度查询回退，改进不完整、失败、重复和压缩响应的识别；未知额度保持未知，不显示为零。网关与原生 Session Token、API rate 分开展示，避免混算。

### 修复与优化：会话、TUI 和代理

- 改进 Herdr 中 Codex 当前会话识别：共享后台进程上报旧 pane 时，可通过本地线程标题和项目路径唯一匹配未归档会话；订阅确认消息不再污染焦点跟踪，也不会把任意最近会话误标为当前会话。
- 统一账号操作按钮、滚动条比例和页面操作区域，改进 Settings 草稿、刷新入口、保存错误及窄屏展示。
- 代理增加可配置的并发请求、Token 估算任务和正文大小限制，默认分别为 16、2、32 MiB；改善限流时机、流式名额释放、错误脱敏和相关头转发。
- 复用 Tokenizer，减少非流式正文的重复缓冲与解析；优化 SSE 分块处理，保留 UTF-8 分片、事件边界和单事件大小限制。
- 整理代理、TUI 事件与 Pulse 模块，并扩展 Git 服务、鼠标命中、换行、页面状态保留、账号操作和资源限制回归覆盖。各平台 CI 与 Docker 串行调度独立 Rust 测试，避免子进程 / 文件锁竞争；统计数据库测试与实际代理一样复用共享 Writer，避免异步最终写入期间反复创建、关闭独立 WAL 写连接而在 macOS 超时。测试内部的并发行为仍照常验证。Git Log 解析兼容 Rust 1.99 的新 Clippy 检查，worktree 回归测试统一比较 Windows 路径表示。
- README 与安装、客户端、导航、代理、Pulse、开发文档同步更新。发布任务读取这份详细说明，并校验 Git 标签、Cargo 版本和 Herdr 插件版本一致。

### 下载、安装与升级

| 平台 | 发布包 |
| --- | --- |
| macOS Apple Silicon | `mux-macos-arm64.tar.gz` |
| Linux x86_64 | `mux-linux-x86_64.tar.gz` |
| Linux ARM64 | `mux-linux-arm64.tar.gz` |
| Windows x64 | `mux-windows-x86_64.zip` |

每个包提供对应的 SHA-256 文件。Windows ZIP 包含程序、使用说明和许可证。源码最低要求 Rust 1.88；Herdr 插件支持 macOS / Linux，需要支持插件的 Herdr 0.7.0+，Git 功能需要系统 `git`。

macOS / Linux 安装或更新 Mux：

```sh
curl -fsSL https://raw.githubusercontent.com/Sunmedalia/mux/main/install.sh | bash
```

安装或更新 Herdr Pulse，在 Herdr 普通终端执行：

```sh
curl -fsSL https://raw.githubusercontent.com/Sunmedalia/mux/main/install.sh | bash -s -- herdr
```

也可使用 `herdr plugin install Sunmedalia/mux` 下载发布版插件；本地源码链接用户在当前 checkout 运行 `bash scripts/install-herdr.sh`。默认快捷键为 Ctrl+B，再按 u；已有 Mux 键位会保留，冲突不会被覆盖。

更新后关闭并重新打开 Mux / Pulse 窗口。需要更新后台代理时，先等待正在运行的请求结束，再执行 `mux proxy stop`、`mux proxy start`；新资源设置与采集改进由新代理进程应用。

Git 暂不提供图形提交拓扑、Stash、Rebase、Cherry-pick、分支删除、图形冲突编辑或逐行暂存。新增、删除、重命名、二进制、权限变更和子模块使用整文件操作；冲突在外部解决后再暂存。
