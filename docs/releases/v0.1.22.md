# Mux v0.1.22

本版为 Herdr Pulse 新增 **File 文件管理**，统一 Token / Git / File 的导航、布局和鼠标操作，重做 Git 的 Actions、分支菜单、Log 与提交详情页面。同时包含 v0.1.21 之后已合入的本地会话浏览、Token / 活跃会话趋势图、主题预览和中英文帮助。

## 1. 新增 File 文件管理

- 页头新增 **FILE**，与 TOKEN、GIT 一起使用固定位置和间距；支持鼠标切换及 `Alt+1 / Alt+2 / Alt+3`，各页保留自己的位置和查询。Settings → Pulse 的启动页也可选择 File。
- 默认跟随原始 Herdr tab 中活动终端的工作目录；聚焦 Pulse 时保留最后目录。手动导航会固定目录，`p` 切换 Follow / Pinned；Home 返回当前终端目录、取消固定并清空筛选。
- 目录优先、按名称排序；显示文件类型图标、大小和修改时间，选中项整行高亮。支持隐藏文件开关、路径面包屑、滚轮、翻页以及可点击和拖动的滚动条。
- **方向键导航**：↑↓ 选择，← / Backspace 返回父目录，→ 进入选中目录，Enter 打开文件或目录。右方向键在选中文件时不会打开编辑器。返回父目录时重新选中刚退出的目录。
- 文件列表顶部常驻无背景的边框 **Find** 输入框：点击或 `/` 输入后实时筛选，Enter / Tab 完成输入，Esc 恢复原查询和位置，`[x]` / Ctrl+U 清空。
- 单击选择、双击打开；右键或 **Actions** 打开底部文件操作菜单，背景保留列表。支持打开、重命名、复制、移动、永久删除、新建文件和新建目录；输入及删除确认同样使用底部弹窗。
- 新建及文件操作不覆盖同名目标；拒绝把目录复制或移动到自身及子目录。复制保留符号链接，删除链接只移除链接本身。永久删除目录会删除目录及其内容，执行前需要确认。
- 从 Actions 进入输入或确认后，Back / Esc 返回原菜单；失败保留草稿，成功刷新原目录。无选中项时禁用文件操作，仍可新建文件和目录。
- 当前目录每两秒静默刷新，保留选择及滚动位置；无变化时不反复显示 Working，也不会因扫描禁用鼠标和切页。用户发起的文件操作显示对应进度与错误。

### 在新 Herdr tab 中编辑文件

打开文件会在同一 workspace 创建并聚焦独立 tab，工作目录为文件所在目录。编辑器优先使用 `$VISUAL`，其次 `$EDITOR`，支持附带参数；未配置时依次寻找 `nvim`、`vim`、`vi`。

文件路径通过独立参数传入，覆盖中文、空格、引号和 shell 特殊字符的回归验证。每次打开创建新 tab；编辑器退出后保留该 tab 并进入交互 shell。未找到编辑器时在 File 页显示错误，编辑器启动失败时在新 tab 显示原因。

### Nerd Font / Unicode 图标

- 默认使用 **Nerd** 图标：文件、目录、链接及常见编程语言、配置、文档、媒体、压缩包、数据库等按类型显示图标和配色，需要终端使用 Nerd Font。
- **Unicode** 模式使用 emoji 图标，例如 📁、🔗、🦀、🐍、⚙️、📄、🖼️、🎵、🎬、📦；两种模式都使用固定两列的图标槽，文件名保持对齐。
- 模式选择集中在 **Mux TUI → Settings → Pulse → File icons**，左右键更改、Ctrl+S 保存、Ctrl+R 丢弃；File 页头不再单独提供图标切换按钮。
- 保留已有图标设置，保存到状态目录的 `pulse-file-icons.json`；打开的 Pulse 会在两秒内更新图标，保留目录、查询、选择、滚动和操作草稿。

## 2. Git 交互与页面调整

### Actions 随页面提供操作

- 原 Ops 统一改名为 **Actions**，位于底部 **Home 左侧**；采用与 File 一致的按钮配色和间隔。
- Actions 通过底部弹窗展示，使用圆角边框，背景保留当前列表、Diff 或 Log。底部仅保留 **Choose / Back**，删除 Type to filter 提示行和菜单项末尾不必要的省略号。
- **Files**：提供整文件暂存、取消暂存、丢弃，以及暂存全部、提交、分支、同步、Log、仓库信息等操作。
- **Diff**：提供整文件与选中差异块操作、前后文件、前后差异块、Wrap ON/OFF、刷新、上次操作结果和返回文件列表。
- **Log**：提供提交详情、较新 / 较旧历史页、搜索、刷新和返回文件列表。
- 不可用操作变暗，键盘跳过；输入、确认和仓库信息的 Back / Esc 恢复原 Actions 位置和查询。换行、文件切换、差异块导航保留对应目标，使用原页面的滚动范围。

### 首页、搜索与底部按钮

- 点击**项目名称**在名称下方展开仓库详情，包括路径、分支、上游、本地领先 / 落后数、最近 Fetch 记录和 Follow / Pinned 状态。
- 点击**分支名称**在名称下方展开真正的分支选择菜单；项目详情和分支菜单均采用与 Actions 相同的圆角边框和配色。选择分支后仍需确认；键盘或 Actions 入口继续支持分支操作。
- Git 文件列表和 Log 顶部使用常驻、无背景的边框 **Search** 输入框。文件路径实时筛选；Log 查询在 Enter 后提交，对当前分支提交标题和正文进行字面搜索。Esc 恢复原查询和位置，Ctrl+U / `[x]` 清空。
- Files 底部保留 Diff / Refresh / Actions / Home；Diff 与 Log 的所有按钮合并到**最下面一行**：Prev / Next / Refresh / Actions / Home。
- Diff 的 Wrap ON/OFF 移入 Actions，`w` 快捷键保留。移除 Files(Esc) 和 Log 的 Details 按钮，Esc 返回仍可用。删除常规滚动提示行并收回空白，实际操作结果和错误仍显示。

### Log 与下一层提交详情

- Git log 入口和页面标题简化为 **Log**。
- 单击仅选择提交；**双击、Enter 或 Actions → Commit details** 进入下一层提交详情页，按页面宽度显示完整消息、统计和补丁，不使用弹窗。
- 支持 ↑↓ / j/k、PgUp / PgDn、Home / End、滚轮与滚动条浏览；Back / Esc / ← 返回原 Log，保留查询、页码、选中提交和滚动位置。
- 双击要求同一提交在 450 ms 内连续点击，缓慢点击或切换目标不会误打开；加载中不会重复发起详情请求。

## 3. 统一导航、布局与滚动

- Token / Git / File 的页头按钮使用固定顺序、位置和宽度档位，切换页面时不再跳动；窄屏同步缩短显示。
- Home 返回**当前功能首页**：Token 返回用量首页，Git 返回当前仓库文件列表，File 返回当前终端目录。
- 移除各页及帮助中的额外横向缩进，内容更贴近边框，仅为滚动条保留必要空间；收紧 Token 指标、账号卡和图表之间的空白。
- 鼠标命中区域与实际按钮保持一致，按钮间保留一列间隔；点击弹窗外关闭菜单，不触发背景操作。
- 修复弹窗向上滚轮不立即滚动的问题：滚轮直接滚动内容，反向滚动立即生效；键盘方向键继续选择操作。Git Actions、分支、详情、输入和确认弹窗支持双向滚动及滚动条拖动；File Actions 同步修复，拖动后不会被选中项强行拉回。

## 4. 本地会话、Usage 趋势与帮助

以下改动已在 v0.1.21 之后合入 main，此次随 v0.1.22 首次纳入 Release：

- Pulse Sessions 改进连续列表、会话标题与详情浏览，优先使用原生标题；无标题时使用项目及短 ID。保留搜索、排序、选择和滚动状态，支持窄屏操作与中英文帮助。
- 主 TUI **F6 Usage** 增加 Gateway / Sessions 数据源切换，顶部按钮或 `g` 切换、`6` 直接进入 Sessions；两边独立保留客户端、周期和位置。Gateway 统计代理请求，Sessions 读取本地累计会话用量，两者不能相加。
- Sessions 支持标题、完整路径、ID 或模型的字面搜索，最近活动 / 最多 Token 排序，以及所有日期 / 跟随统计周期筛选。宽屏显示详情预览，Enter 进入可滚动详情页。
- 增加本地 **Token 用量趋势与活跃会话趋势**，宽屏并排、窄屏上下排列；支持日 / 周 / 月 / 年周期，并跟随客户端、查询和筛选。活跃会话按每个时间桶去重；缺失活动时间或不完整日志显示说明，不用累计 Token 伪造趋势。
- Display / Pulse 主题设置提供独立预览；Graphite 的 Call Health 以绿色表示成功、红色表示失败。
- Pulse 用量、会话、图表、Git、Log、File 提供中英文帮助及右上角入口，帮助与返回操作保留原页面上下文。

## 6. 安装与升级

在 Herdr 普通终端中安装或更新插件：

```sh
herdr plugin install Sunmedalia/mux
herdr plugin action invoke mux.open
```

安装钩子按 manifest 版本下载本版程序并验证 SHA-256 与程序版本。已有源码链接用户可在原 checkout 更新后运行：

```sh
bash scripts/install-herdr.sh
```

独立程序可使用：

```sh
mux update
```

更新后关闭并重新打开 Mux / Pulse 以加载新程序；编辑器中新开的 File tab 使用新入口。图标样式在 Settings → Pulse → File icons 配置。完整使用说明见 [Herdr Pulse](https://github.com/Sunmedalia/mux/blob/v0.1.22/docs/pulse.md)、[安装文档](https://github.com/Sunmedalia/mux/blob/v0.1.22/docs/installation.md)和[导航说明](https://github.com/Sunmedalia/mux/blob/v0.1.22/docs/navigation.md)。
