# Mux v0.1.23

本版新增原生会话继续与跨 AI 接管，修复恢复终端后的 Pulse 开关，并更新 TLS 安全依赖。

## 会话继续与 AI 接管

- 完整 Mux 的 Usage → Sessions 和 Pulse 的 Sessions 列表、详情新增 **AI / Take over / Switch AI** 入口，可选择 Claude、Pi、Codex 或 Grok。按 `a` 打开选择，Enter / Start 启动；Pulse 的 `A` 可直接接管当前会话。
- 选择原客户端时使用精确会话 ID 恢复，Pi 使用会话日志路径。在 Herdr 中唯一识别到原会话 pane 时直接聚焦，否则打开新 tab。
- 选择其他 AI 时，在原项目目录启动目标客户端，通过本地完整文本交接文件传递持久化消息、工具调用、工具结果与已有摘要。原进程继续运行，交接为启动时快照，不同步后续消息。
- 交接文件在目标 CLI 运行期间保留，退出后清理；图片和二进制仅保留引用与说明，不包含隐藏推理。日志缺失或解析失败时显示错误。
- Herdr 新 tab 在 AI 退出后保留交互终端；独立运行时释放当前终端，并在 AI 退出或启动失败后恢复 Mux 页面和浏览位置。
- Pi 会话支持 `PI_CODING_AGENT_DIR`，默认读取 `~/.pi/agent/sessions`；Pulse 增加 Pi 客户端筛选。未安装的客户端显示不可用，子代理会话暂不支持接管。

## Pulse 开关修复

恢复的 pane 可能保留 **Mux Pulse** 标签，但已运行 shell 或其他代理。切换 Pulse 时跳过这些 pane，继续查找真正运行的 monitor；找到时关闭 monitor，未找到时新建。保留原终端与代理进程，避免因旧标签导致开关失败。

## 依赖安全修复

锁定 `rustls` 从 0.23.45 更新至 0.23.46，修复 CI 安全审计报告的 RUSTSEC-2026-0346、RUSTSEC-2026-0347、RUSTSEC-2026-0348 和 RUSTSEC-2026-0349。同时将 `zip` 从 0.6.6 升级至 9.x，修复本次 CI 新检出的 RUSTSEC-2026-0367、RUSTSEC-2026-0368 和 RUSTSEC-2026-0369，并适配 Windows ZIP 测试接口。发布继续要求依赖审计通过。

## 发布平台与验证

提供 macOS ARM64、Linux x86_64 和 Linux ARM64 的程序归档及 SHA-256，共六个下载资产。Windows 保留源码兼容与原生 CI 验证，本版不发布 Windows 二进制；macOS Intel 需从源码构建。

CI 包含格式检查、全目标 / 全功能 Clippy 与回归测试、Rust 1.88 最低版本检查、Windows 原生测试、依赖审计、Docker 卸载安全回归及三个发布平台构建。新增回归覆盖会话恢复参数、跨客户端交接、终端恢复，以及跳过旧 Pulse 标签并查找活动 monitor。

## 安装与升级

独立程序使用 `mux update`。Herdr 插件使用：

```sh
herdr plugin install Sunmedalia/mux
herdr plugin action invoke mux.open
```

更新后重新打开 Mux / Pulse。Herdr 插件需要 Herdr 0.7.0+，源码构建需要 Rust 1.88+。会话接管需安装目标 AI 客户端，沿用目标客户端自身的模型、账号与权限设置。更多说明见 [Pulse 文档](https://github.com/Sunmedalia/mux/blob/v0.1.23/docs/pulse.md)。
